# StalkExchange — Frontend

This is the React Router v7 frontend for the StalkExchange stock metrics app.

For full setup and run instructions, see the [project README](../README.md) in the repository root.

## Quick start (frontend only)

```bash
npm install
npm run dev       # dev server at http://localhost:5173
npm run build     # production build
npm start         # serve production build at http://localhost:3000
```

The backend API must be running at `http://localhost:8000` for data to load.
See the [root README](../README.md) for backend setup.
